# saborExpress-POO
Aplicação criada durante o curso de Python Orientado a Objetos da Alura.

Durante a criação desta aplicação aprendi e pratiquei conceitos como:

- Classes e objetos;
- Construtor __init__;
- Atributos de instância;
- Atributos de classe;
- Métodos de instância;
- @classmethod;
- @property;
- Composição/relacionamento entre objetos;
- Listas de objetos;
- Validação de dados.

**Funcionalidades utilizadas no projeto:**

- Cadastro de restaurantes através de objetos;
- Listagem dos restaurantes;
- Controle de status (ativo/inativo);
- Sistema de avaliações;
- Cálculo de média das avaliações;
- Associação entre Restaurante e Avaliacao.
